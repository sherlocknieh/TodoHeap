# 视图详解

工作区左侧栏的「视图」分组提供三个入口：任务图、任务表、回收站，其中任务图是默认视图。堆视图的路由仍然保留，但侧栏入口已隐藏。

左侧活动栏另有「清单 / 日程 / AI」三个主入口，每个入口对应一套侧栏内容：清单展示视图入口，日程展示日程概览，AI 展示优化操作与模型入口。点击当前入口收起或展开侧栏，点击其他入口则切换视图并展开对应侧栏。活动栏顶部的 Logo 点击可回到主页；底栏左侧的开关会把活动栏与侧栏整体收起以腾出空间，再次点击开回并恢复原来的侧栏状态。

每个视图的顶栏右侧都有同一个右栏开关，打开后承载该视图自己的内容：任务表、任务图、堆与回收站是任务详情，日程是选中日程的详情，AI 是对话上下文。

左侧栏与右侧面板都可以拖动内侧边缘调整宽度，宽度会记住；拖到最小宽度后继续拖动一小段才收起该面板。

## 视图对比

| 视图 | 形态 | 适合 |
| --- | --- | --- |
| 任务图（默认） | 思维导图式任务图 | 梳理结构、批量调整层级 |
| 任务表 | 线性清单，支持多级缩进 | 日常增删改、按顺序推进 |
| 回收站 | 已删除任务的列表 | 找回误删任务 |
| 堆视图（入口隐藏） | 按优先级排序的执行队列 | 决定下一个做什么 |
| AI Agent | 对话式管理任务、日程与偏好 | 复杂增删改、批量整理 |
| 日程 | 日历事件按日期分组 | 看接下来几天有哪些日程 |

## 任务表

从侧栏「视图」进入，适合逐条编辑。

### 界面结构

- 主区域顶栏统一显示当前视图标题；任务表的顶栏右侧只放进度（待办 / 已完成数量），排序方式与一键展开/折叠在「待办」标题栏右侧
- 顶栏下方是整行可聚焦的添加框，写标题回车即存
- 任务按层级缩进排列，默认展开前两层；父任务左侧的圆形 +/− 可以折叠/展开子任务，「待办」标题栏右侧的圆圈按钮一次展开或折叠整张列表
- 系统根任务「全部任务」不显示成任务行，列表展示的都是它下面的顶层任务；统计也不把它算进去
- 已完成的任务收在列表末尾的「已完成」区域，没有已完成任务时不占位置
- 单击任务会在右侧打开详情面板
- 截止时间标签按紧急程度着色：已逾期为红色、当天为绿色，其余为中性色
- 页面底部的输入栏用一句话描述任务，交给 AI 拆解

### 常用操作

| 操作 | 方式 |
| --- | --- |
| 新增任务 | 顶部输入框写标题，回车 |
| 添加子任务 | 任务行「更多」菜单 → 添加子任务 |
| 完成 / 取消完成 | 任务行左侧复选框 |
| 重命名 | 双击标题，回车保存，Esc 取消 |
| 查看与编辑详情 | 单击任务行 |
| 设置截止时间 | 点任务行右侧的日历按钮或截止标签，直接展开月历面板，可选今天、明天、一周后或具体日期与时分 |
| 排序 | 「待办」标题栏右侧的排序下拉框 |
| 调整顺序与层级 | 拖拽任务行 |
| 删除 | 任务行「更多」菜单 → 删除任务，进入回收站 |

任务行的操作按钮常驻显示：日历按钮或截止时间标签负责设置时间，右侧竖三点「更多」菜单收着添加子任务与删除。

### 排序

「待办」标题栏可在手动顺序、截止时间、创建时间、耗时之间切换，排序只重排同级任务，子任务跟着父任务走并各自排序。

排序方式属于显示偏好，保存在本机；「手动顺序」来自父任务的子任务列表本身（`child_ids` 的数组顺序），拖拽调整后写回的就是这个顺序。顶层的顺序由系统根任务「全部任务」维护，所有顶层任务都挂在它下面。

截止时间、创建时间、耗时这三种排序只影响显示，不会改写手动顺序。

### 拖拽调整

- 拖到另一行的上边缘或下边缘：插到该任务前面或后面，成为同级；只调整落点所在父级的顺序，该任务在其它父级下的位置不受影响
- 拖到另一行的中间：成为该任务的子任务；只摘掉拖拽来源那一侧的父链接，任务原有的其它父级保留
- 拖到顶层任务的上下边缘：移到顶层，挂回「全部任务」下
- 拖拽会真正修改父子关系与顺序，刷新后仍然生效
- 同一任务可以出现在多个父级下，每个父级各自维护自己的顺序

不能把任务拖进自己或自己的子任务里，拖拽时会被拒绝并提示原因。

### 操作反馈与撤销

删除任务、切换完成状态后，底部会出现提示条。带「撤销」的提示在几秒内可点撤销，撤销同样会同步到服务器。

## 任务图

打开应用后的默认视图。用思维导图展示同一张任务图，适合先理清结构再逐条执行。

### 界面结构

- 导图占满活动栏以外的区域，底栏保留导航开关、统计与同步状态；侧栏可随时打开，以浮层覆盖导图，开关侧栏不会移动导图
- 每个任务只出现一次，所有父引用都画成连线，环用回边绕回表示
- 折叠某个父级只收起它自己的连线；任务只要还有一条展开的父链就保持可见
- 右下角工具栏的方向按钮在两种横向布局之间切换：从左到右、从右到左，默认从左到右
- 同一工具栏的展开/收起全部按钮（四箭头向外 / 向内）在「全部展开」与「只剩根节点」之间切换：展开全部后自动回到全景，收起全部后只留根节点并聚焦它；布局以根节点为坐标锚点，展开/折叠时根节点在画面上保持原位
- 根节点是系统根任务「全部任务」，按所选方向分层展开；它不能被改名、勾选完成或删除，所有顶层任务都挂在它下面
- 单击节点选中任务；顶栏右栏开关可在右侧打开该任务的详情，侧栏以浮层覆盖导图时不影响布局
- 滚轮在选中节点上缩放、空白处上下平移；按住 Ctrl（Mac 为 Cmd）时滚轮在任意位置都缩放。触控板双指捏合同样缩放。拖拽空白处或根节点平移，点右下角目标按钮可在「全景」与「聚焦根节点」之间切换，手动移动后第一次点击先回到全景
- 选中节点时自动把它水平移到画布中央，纵向保持原来的屏幕位置（仅当节点快要移出视口时拉回可见范围），视野固定为父级、当前、子级三栏，与父子关系实际分布无关；画布宽度变化（如开关详情面板）时会重新贴合三栏
- 每个节点出边一侧都有圆形按钮：有子任务时是折叠开关；叶子节点悬停或选中时显示加号，单击新建子任务，也可拖到其它节点把那个任务挂到当前节点下
- 鼠标移到节点上时边框变成半透明绿色；选中后是实色绿框加淡绿底，两者粗细相同，只靠浓度区分
- 节点右侧常驻竖三点按钮，点开的菜单可以设置日期、新建子任务、复制节点或删除该任务；菜单在按钮下方展开，靠近画布边缘时自动翻到另一侧
- 在节点上点右键同样能唤出菜单，菜单从指针处展开
- 节点文字最多显示三行，超出部分加省略号，全文在右侧详情里；原地编辑时节点框随输入行数长高，节点内不出现滚动条

### 拖拽节点

按住一个节点拖到另一个节点上松开，即把源任务挂为目标任务的子任务。默认行为由源任务现有的父级数量决定：

- 拖到节点中间：挂为目标任务的子任务
  - 只有一个父级时直接移动：从原父级摘下，挂到落点节点末尾，不弹提示
  - 有多个父级时新增链接：保留原有父级，形成多父关系；底部提示条可撤销，并提供「改为移动（断开旧连接）」，点了才会摘掉该任务的其余父链接
- 拖到节点的上四分之一或下四分之一：插到该任务前面或后面，成为同级；只调整落点所在父级的 `child_ids` 顺序，拖动时会在落点插入占位槽，兄弟节点让开
- 从节点出边一侧的折叠/加号按钮拖出时只建立链接，不搬动任务原有父级
- 建链接或拖进节点后，落点父节点如果处于折叠状态会自动展开；新连线同时像被点击一样高亮（强调色、加粗并出现中点删除按钮），不必在一堆细线里找它。根任务发出的边不可删除，只高亮
- 拖动时指针处显示源节点的副本（原节点淡出），拖进目标时目标节点高亮表示可以挂接；只有从折叠/加号按钮拉线时才显示预览线：弯曲方式与正式连线一致，拖动期间用强调色高亮
- 目标已经是源任务的子任务、或目标在源任务的子树里（会成环）时会被拦截并提示
- 回边节点只是引用，不能作为拖拽起点或落点

### 键盘操作

选中节点后画布获得焦点，可直接用键盘增删改：

| 按键 | 作用 |
| --- | --- |
| `Enter` | 新建同级任务，插在当前节点之后并立即进入重命名 |
| `Tab` | 新建子任务，挂到当前节点下并立即进入重命名 |
| `F2` / 双击节点 | 重命名当前节点，`Enter` 保存、`Esc` 取消；编辑中 `Shift+Enter` 插入手工换行 |
| `Delete` / `Backspace` | 删除当前节点及其子任务，底部提示条可撤销 |
| `Space` | 切换完成状态 |
| 方向键 | 沿布局方向移动：主方向进入子级或回到父级，交叉方向在同级之间切换 |
| `Esc` | 取消选中 |

方向键的含义跟随布局方向，例如从左到右时 `→` 进入子级、`←` 回到父级、`↑` `↓` 切换同级。回边节点只是引用，不能直接重命名或删除，选中后会跳到被引用的真实任务。

## 回收站

删除的任务先进入回收站，可恢复或彻底清除。同一任务只出现一次，不会因多父关系重复列出。系统根任务「全部任务」不会被删除，也不会出现在回收站里。

### 操作

- 未选中任务时，头部只提供「清空」
- 单击某条任务后，头部按钮变为针对该任务的「恢复」「永久删除」；Ctrl/⌘ 或 Shift 多选后，头部提供批量「恢复」「永久删除」

### 恢复限制

父子任务必须按顺序恢复：父任务仍在回收站里时，直接恢复子任务会被拦截，并提示先恢复父任务。批量恢复则自动把这类任务恢复到根节点，避免出现没有父级的孤立节点。

## 堆视图

按优先级得分从高到低排列任务，左侧是堆结构可视化，右侧是排序后的列表。节点颜色对应优先级等级，数字为得分。

::: tip 入口说明
堆视图目前没有侧栏入口，可直接访问 `/app/heap` 查看。

## 日程

从活动栏的日程入口进入，按日期排列 `schedules` 里的日历事件，任务不会出现在这里：

- 今天、明天优先，其余按日期升序
- 同一天的事件按开始时间排序，显示时间区间
- 整日事件标为「全天」
- 单击事件行会在右侧打开该日程的详情，标题、起止时间、地点、链接、参与人、状态、颜色、提醒与备注可直接修改，保存后写回 `schedules`
- 详情面板底部的「删除」可以移除该日程，换选其他事件时草稿跟着切换，不会带到另一条日程

右上角提供「导入 / 导出 / 订阅」三个入口：导入 `.ics` 日历、导出日程文件、跳转到设置页管理订阅链接。详见 [日历导入导出与订阅](./calendar.md)。

查看任务请使用任务表或任务图。

## AI Agent

从活动栏的 AI 入口进入，这里是一个对话式 Agent：

- 用一句话描述需求，Agent 会调用工具读取或修改任务与日程
- 拆解、新建、优化都在对话里完成，清单视图不再有单独的 AI 按钮
- 左侧侧栏管理会话，模型在「设置 → 模型接入」中配置
- 删除、清空回收站等破坏性操作会先弹出确认

详见 [AI 智能功能](./ai-features.md)。

## 视图切换

点击左侧栏「视图」分组中的条目即可切换；窄屏下切换后侧栏会自动收起。

视图与路由一一对应：

| 视图 | 路由 |
| --- | --- |
| 任务图 | `/app/graph` |
| 任务表 | `/app/list` |
| 回收站 | `/app/trash` |
| 堆视图 | `/app/heap` |
| 日程 | `/app/schedule` |
| AI Agent | `/app/ai` |
