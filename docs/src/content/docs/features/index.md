# 功能现状

本目录按功能域说明已经实现的行为与关键落点，与[用户指南](../user/index.md)讲「怎么用」互补。

## 编写规则

- 只写当前实现：描述现在的行为、约束与代码位置。行为改变时直接改写对应描述，不记日期、需求原话与演进过程。
- 缺陷与修复写进 `docs/src/content/docs/dev/logic/` 下对应的机制文档。
- 功能移除时删掉对应描述，不留「已移除」「已还原」的痕迹。
- 不重复用户指南的操作步骤；需要展开说明时链接过去。
- 按主题分节，用列表描述现状与关键函数或文件。
