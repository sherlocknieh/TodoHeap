# 日历与订阅

本页说明日程页与日历导入导出的当前实现。使用方法见[日历导入导出与订阅](../user/calendar.md)。

## 手动新建日程

- 入口：日程页主区域顶栏的「新建」按钮（窄屏被隐藏）、「当天日程」标题右侧的 + 图标、当天没有日程时空状态里的「新建日程」按钮。三处调用同一个 `createSchedule`。
- 时间：`defaultScheduleRange(选中日期)` 把选中日期与当前时分拼成开始时间，结束时间固定为一小时后；用户可在右栏改。
- 写入：直接调 `scheduleStore.createSchedules` 落一条标题为「新日程」的事件，成功后选中它并打开右栏 `ScheduleDetailPanel` 继续编辑。
- 与导入、Agent 创建共用同一套字段归一化；用户直接关掉面板时这条记录保留，需要时再删除。
- 点日程列表项、或新建成功后，右栏详情都会自动展开（窄屏下浮在内容之上），可直接编辑。

## 编辑日程

- 右栏 `ScheduleDetailPanel` 编辑标题、时间、地点等；定时事件在「开始」与「结束」之间有一行「时长（小时）」。
- 时长与结束时间互算：改时长（数字输入，或 30 分钟 / 1 小时 / 2 小时 / 3 小时快捷按钮）会按开始时间算出结束时间；改开始时间后按当前时长顺延结束；改结束时间则把时长回填成实际间隔。
- 链接、状态、颜色、提前提醒收在「更多选项」折叠组里；选中日程在这些字段有非默认值时自动展开，否则保持收起，也可手动切换。
- 全天事件不显示时长，结束按日期计算。修改都只作用于草稿，点「保存」才落库。
- 保存成功后收起右栏并清掉选中；保存失败留在面板里显示错误。
- 点面板以外的区域（空白、日期导航、顶栏操作等）会清掉选中并收起右栏，宽屏停靠时也一样。
