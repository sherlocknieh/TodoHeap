# 任务与层级

本页说明任务本体相关的当前实现：创建、编辑、完成、层级与回收站。使用方法见[任务管理](../user/task-management.md)。

## 详情右栏的「时间」独立分区（2026-11-29）

- 需求：任务详情里的截止时间与耗时不再挤在「详情」分区，改成单独一栏。
- 布局：右栏分区顺序变为「详情 / 时间 / 描述 / 子任务」，详情与时间都按内容定高；时间分区内截止时间与耗时仍上下堆叠（`grid-cols-1`）。
- 实现：`components/TodoDetailEditor.vue`「[时间分区]」与 `useSectionStack` 的 `timing` 分区；折叠状态沿用本地 `detail-sections`。机制见[详情右栏与任务图布局](../dev/logic/layout-detail-panel.md)。

## 详情右栏标题上方的父链（2026-11-29）

- 需求：任务详情标题上方用小字显示完整父链，多父任务也能看到全部上级。
- 展示：DAG 去重后的祖先层——按距当前任务的跳数分层，远层在前，同层用 `/` 表示并列父级，层间用 `›`（如 `项目 / 另一支 › 子项目 / 分支子`）；同一祖先只出现一次，历史环数据也会自然终止。
- 折行：与标题输入框一样左对齐，宽度不足自动折行，每个祖先保持单行。
- 封顶：唯一祖先 40、深度 20，超出时行末加 `…`。
- 实现：`utils/taskChain.js` `ancestorLayersOf`（单测 `taskChain.test.js`）；`components/TodoDetailEditor.vue`「[父链/面包屑]」。机制见[详情右栏的父链展示](../dev/logic/task-chain.md)。
- 回收站任务不在任务数组里，父链整行隐藏。

## 禁止环形依赖（2026-11-29）

- 需求：父子关系允许多父，但不允许成环；把父任务挂到自己后代下会让父链、删除传播与完成任务树失去终点。
- 判定：新增「父 → 子」链接时，若子任务就是自己或父任务在子任务子树里，即判为成环；只校验本次新增的子 ID，历史环数据仍可读写。
- 前端：`stores/todos.optimistic.js` 的 `updateTodo` 在乐观写入与入队前统一拦截，失败提示「禁止形成环形依赖」，不同步、不写快照。
- 入口：详情面板「链接为子任务」候选排除自身、已有子级与全部后代；Agent 工具 `link_todo` / `move_todo` 提前报错；任务图拖拽沿用原拦截。
- 数据库：`trg_todos_prevent_cycle` 在 `BEFORE INSERT OR UPDATE OF child_ids` 时按新增子 ID 递归检查，绕过前端也写不进环；历史环不清理。
- 机制见[环形依赖的写入拦截](../dev/logic/task-cycle-guard.md)。

## 行内菜单文案与顺序（2026-11-28）

- 需求：任务行竖三点菜单按使用频率重排，去掉与层级无关的「链接」说法，让图标表达动作结果。
- 顺序：添加子任务提到首项，其后为标记完成、完成任务树、在任务图中查看、脱离父任务、删除任务。
- 文案：`取消链接` 改为 `脱离父任务`，列表行菜单与详情面板子任务行悬停按钮同步；`节点视图` 改为 `在任务图中查看`；断开后的提示改为「已脱离父任务」。
- 图标：完成任务树改用叠加双勾（`AppIcon` 的 `checks`），列表行菜单与任务图节点菜单一致。

## 完成任务树（2026-11-28）

- 需求：任务列表行菜单与任务图节点菜单都提供「完成任务树」，一次收掉整棵子树，避免逐条勾选。
- 范围：任务本身与沿 `child_ids` 可达的全部后代；多父任务只处理一次，环内终止；`child_ids` 里残留的已删除 ID 静默跳过，不报「任务不存在」。
- 完成时间：只给未完成的任务写同一个 `completed_at`，已完成的保留原时间；任务本身已完成时不再改动它。
- 撤销：提示里可整批撤销，把这次改过的任务恢复为未完成。
- 实现：`utils/taskGraph.js` `collectIncompleteTreeIds`；`stores/todos.optimistic.js` `completeTodoTree`；`components/TodoListItem.vue` 与 `components/MindMapWrapper.vue` 提供菜单入口；页面处理在 `pages/todo/TodoList.vue`、`pages/todo/TodoGraph.vue` 的 `completeTaskTree`。机制见[完成任务树](../dev/logic/task-complete-tree.md)。
- 验证：`utils/taskGraph.test.js` 覆盖跳过已完成、环与多父、任务不存在。

## 添加栏固定在列表底部（2026-11-29）

- 需求：快速添加/搜索从列表顶部移到内容区底部，长列表下随时能输入，不必先滚回顶部。
- 位置：`pages/Todo.vue` 的「待办底栏」`#main-bottom-bar` 放在中栏滚动容器之后（`shrink-0`），`pages/todo/TodoList.vue` 用 `Teleport defer` 注入添加框，输入框因此不随列表滚动；外层内距与列表内容一致（`mx-auto max-w-3xl px-8`），卡片再用 `ml-[22px]` 与任务行左缘对齐。
- 连带调整：顶栏不再显示「N 项待办 / N 项已完成」统计，数量只在各分组标题的徽标里；命中数提示从输入框下方移到上方，仍贴着添加框。
- 新建后：任务照旧头插到根任务首位，`pendingEdit` 触发行内编辑，输入框获得焦点时浏览器会把新行滚回可视区。

## 添加栏兼任搜索（2026-11-21）

- 需求：任务添加框复用为搜索框，由左侧圆钮切换模式，避免再造一个搜索框。
- 模式：`addMode` 在 `add` / `search` 间切换，不持久化；新建态的草稿与已选截止时间在切走再切回时保留。
- 高度：容器用 `min-h-[42px]` 与任务行对齐，搜索态即便只剩圆钮和输入框也不会变矮。
- 输入：同一个 `input` 通过 `addInputModel` 双向绑定，占位文案随模式变化；新建模式右侧保留截止时间与提交按钮，搜索模式有词时给清空按钮。
- 过滤：`utils/taskGraph.js` 的 `filterTasksByTitle` 保留命中节点与祖先链，回边行不重复计入；搜索期间给 `TodoListItem` 传 `ignore-collapse`，命中行不受折叠影响。
- 交互：回车在新建模式保存任务、在搜索模式选中第一条命中；Esc 先清空搜索词，再按一次回到新建模式。
- 新建后：`addTodo` 成功后把新任务写进 `pendingEdit` 并选中，行内编辑随即可用，和列表 Tab/Enter 新建的处理一致。
- 快捷入口：「待办」标题栏右侧常驻 + 按钮（`h-7 w-7` 的浅绿底 + 绿色描边，比同排图标按钮醒目），`focusAddInput` 把焦点放到底部添加栏；搜索态先切回新建，保证输入就是新建任务。
- 高亮：`MiddleEllipsis` 新增 `highlight`，把标题按命中词切成片段并给命中片段加强调底色；只标可见片段，截断掉的部分不参与匹配显示。

## 多父任务的列表行样式统一（2026-11-21）

- 需求：同一任务挂在多个父级下时，各处的行样式应一视同仁；「脱离父任务」从悬停按钮改为菜单项。
- 卡片：`TodoListItem.vue` 去掉回边行（`_isRef`）的虚线边框、灰色标题、链接图标与独立操作区，勾选圈、标题颜色、截止时间入口与更多菜单都与实体行一致。
- 写操作：完成状态、截止时间、编辑、跳转、删除统一经 `selectableIdOf` 落到真实任务 ID；`statusMap` 也按真实 ID 记录，两处出现同时反映完成状态。
- 菜单：「更多操作」在「添加子任务」与「删除任务」之间新增「脱离父任务」，所有挂在父级下的行（`_level > 0`）都有，断开本行所在的父链接；最后一个父级被断开时任务回到顶层。
- 菜单首项：「标记完成」放在最前，走与勾选圈相同的完成流程，任务完成后行移出待办区。
- 脱离父任务后：`TodoList.vue` 的 `unlinkTask` 把选中项切到该任务，另一个父级下出现它的那一行随之高亮，详情面板同步显示该任务。
- 保留差异：回边行没有自己的子级，左槽恒为勾选圈；不可拖拽、不可多选，也不作为拖拽落点。
- 机制见[任务表树状连线](../../dev/logic/task-list-tree-lines.md)与[任务顺序](../../dev/logic/task-order.md)。

## 连续新建标题自动编号（2026-11-21）

- 需求：连续添加多个同级新任务时标题不再全部是「新任务」，自动按序号区分。
- 口径：参考标题末尾有数字就续号（`步骤 2` → `步骤 3`，保留分隔符与前导零）；没有数字则用默认标题从 1 开始取最小未占用编号（`新任务 1`、`新任务 2`）。
- 入口：任务图 Enter 建同级以当前节点为参考；任务图子级、列表新建子任务与顶栏新建没有同级参考，按目标父级现有子任务编号，默认标题统一为 `新任务 1`、`新任务 2`。
- 实现：`utils/taskTitle.js` 的 `nextTaskTitle` / `childTitlesOf`，同级标题按父级 `child_ids` 取，已删除残留 ID 跳过；调用点在 `TodoGraph.vue` 的 `createTask`、`TodoList.vue` 的 `addSubtask`、`Todo.vue` 的 `createNewTask`，机制见[任务创建逻辑](../../dev/logic/task-create.md)「连续新建时的标题编号」。
- 验证：`frontend/src/utils/taskTitle.test.js` 覆盖续号、前导零、跳号、默认编号与同级标题顺序。

## 回收站卡片样式统一（2026-11-21）

- 需求：回收站任务卡片向任务表看齐，避免同一任务在两个页面高度、缩进与控件不一致。
- 卡片：内距 `py-1.5 pl-2 pr-1.5`、行距 `space-y-1.5`，与任务表行一致。
- 缩进：根行 22px、每层 28px，与任务表卡片左缘公式一致。
- 控件：折叠开关改用圆形 +/−；无子任务时用 18px 垃圾桶占位，保证标题左缘对齐。
- 元信息：删除时间用纯文本，不做胶囊；行内恢复/永久删除按钮常显。
- 按天分组：回收站按子树根的删除日期分组，标题为「今天 / 昨天 / M月D日 + 当天数量 + 分隔线」，点标题可收起/展开；口径见[回收站按天分组](../../dev/logic/trash-day-groups.md)。
- 顶栏入口：未选中时只有「清空」；单条或多选后才出现「恢复」，不提供「恢复全部」。

## 已完成按天分组（2026-11-20）

- 需求：任务表的「已完成」区按完成日期分隔，而不是一整串平铺。
- 实现：[TodoList.vue](../../../../frontend/src/pages/todo/TodoList.vue) 的 `completedGroups` 调用 `utils/completedGroups.js` 的 `groupCompletedByDay`。
- 口径：以 `completed_at` 的本地自然日为分组键；标题为「今天 / 昨天 / M月D日」，跨年补「YYYY年」；每天标题后跟当天数量与一条分隔线。
- 顺序：分组按日期倒序，最新完成的一天在最上面；组内任务按完成时间倒序。
- 折叠：日期分隔整行（含分隔线）可点击，收起/展开当天任务；收起时标题与数量仍显示，状态只存在当前会话。
- 单条删除：每条右侧有删除按钮，走软删除进回收站，提示里可撤销；与整区「清除已完成」互不影响。
- 完成时间：每条右侧显示完成时分（`HH:mm`），日期由所在分组标题给出。
- 多选：待办区与已完成区都支持 Ctrl/⌘ 切换、Shift 连选；选中后操作出现在各自分区的标题栏，可批量删除并整批撤销，机制见[任务多选](../../dev/logic/task-multi-select.md)。
- 回收站多选：同样支持 Ctrl/⌘ 与 Shift，顶栏出现批量恢复与批量永久删除；父任务仍在回收站时，批量恢复会把该任务恢复到根节点。
- 验证：`frontend/src/utils/completedGroups.test.js` 覆盖分组、组内排序、标题与空值。

## 截止时间胶囊（2026-11-20）

- 需求：日期清除逻辑交回任务行/快速添加栏的截止标签（胶囊），面板里不再重复放「清除」。
- 实现：[DateTimePicker.vue](../../../../frontend/src/components/DateTimePicker.vue) 新增 `triggerClear`：截止标签入口开启后，悬停胶囊时左侧的时钟图标原地换成 ×，点击清空 `v-model` 并 `confirm`；面板内的「清除」在 `triggerClear` 时不再渲染。
- 保留：详情编辑器与日程详情面板用默认输入框触发器，清除仍在面板内，避免点输入框右侧误清空。
- 机制见[日期时间选择器](../../dev/logic/date-time-picker.md)。
