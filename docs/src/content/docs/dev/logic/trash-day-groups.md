# 回收站按天分组

回收站列表按删除日期分隔，口径与已完成区一致：本地自然日、最新的一天在最上面、标题可点折叠。

## 分组键

- 用**子树根**的 `deleted_at` 作为整个子树的日期来源，子任务跟着父任务走，避免父子被拆到两个日期。
- 子树根指回收站内沿 `parent_id` 上溯到的最顶层祖先；多父引用行不参与分组。
- 只对当前可见行分组：单条任务折叠后，其后代不进入任何一组。
- 删除时间缺失或非法的行归入「未知时间」，固定排在最后。

## 标题与折叠

- 标题格式复用已完成区的日期工具：今天 / 昨天 / M月D日，跨年补年份；后面跟当天数量与分隔线。
- 点整行标题收起或展开当天任务；折叠状态只存在当前会话。
