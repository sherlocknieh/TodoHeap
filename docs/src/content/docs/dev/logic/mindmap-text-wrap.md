# 节点文字折行与节点高度

任务图的节点文字由常驻 `textarea` 承载：平时只读显示、双击原地编辑，两个状态共用同一个元素，只是取值不同。

## 实现

- 只读态的值是 `node.lines.join('\n')`，`node.lines` 由 `wrapLines` 折好行；编辑态的值是原始 `editingText`，交给浏览器折行。
- 节点高度由 `measureNode` 按 `node.lines.length` 算出（`paddingTop + 行数 × lineHeight + 12`），布局据此摆放节点。
- 编辑中的节点用 `editingText` 参与测量且不设行数上限，所以节点框与输入框随行数一起长高，不出现内部滚动条；非编辑态按 `maxLines` 截断并加省略号。
- 手工换行（`Shift+Enter`）在 `wrapLines` 里按硬换行处理，空白行也占一行。
- 完成态的变灰、删除线（节点文字）与整体 0.55 透明度（`nodeOpacity`）只在显示态生效；进入编辑后文字回到正常颜色、无删除线，节点组不透明，避免输入时读不清。
- 有截止的任务在节点右区放截止胶囊（与任务行同款 chip）。正文宽度 = 节点宽 − 左右内边距 − 勾选框占位 − 三点按钮占位 − 胶囊宽度；胶囊宽度由 `chipChrome`（描边、内边距含悬停撑开给 × 的右内边距、图标、间距）加上按 10px 量出的文案宽度得到，文案变长会把标题挤窄、可能多折一行。

## 折行规则

`wrapLines(text, maxWidth)` 按**真实像素宽度**断行，规则与输入框里的浏览器排版对齐：

| 内容 | 断行点 |
| --- | --- |
| CJK / 全角字符 | 逐字可断 |
| 西文、数字、标点 | 按词断，不拆词 |
| 比整行还长的词（链接等） | 先按整行宽度拆成单字，对应输入框的 break-word 行为 |
| 行尾空白 | 不触发换行 |
| `\n` | 硬换行 |

宽度来自 canvas 的 `measureText`，字体取容器计算值加 `font-medium`（`500 13px <font-family>`），并要求 canvas 的字体串解析成功，否则回退 `sans-serif`。单字与词的宽度有缓存，输入时不重复量。

## 验证

1. 长中文标题：节点显示与双击进入编辑后，断行位置、行宽完全一致；
2. 长英文句子：不出现单词被拆到两行，编辑前后断行不变；
3. 混合中英文与数字：显示行数等于编辑行数，节点底部不裁字、也不留大块空白；
4. 粘贴一条超长无空格串（URL）：按整行宽度拆开，节点高度随之增加；
5. `Shift+Enter` 手工换行后提交：节点保持硬换行，行数不变。
