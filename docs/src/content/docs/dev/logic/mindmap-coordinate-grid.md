# 任务图坐标网格

任务图的坐标网格是铺在 SVG 最底层的显示辅助：数值是任务图的世界坐标，位置由当前视口反算。它不参与布局、节点命中与数据读写，开关与配色都只影响画布本身。功能行为见[视图与交互](../../features/views.md)。

## 坐标空间

| 空间 | 原点 | 用途 |
| --- | --- | --- |
| 布局世界坐标 | 根节点左上角 | `computeGraphLayout` 写出的 `node.x` / `node.y` |
| 网格读数坐标 | 根节点出边按钮圆心 | 世界坐标减去按钮中心偏移，只影响网格读数 |
| 屏幕坐标 | 画布左上角 | 经过 `translate(view.x view.y) scale(view.scale)` 之后 |

- 换算关系是 `screen = world × scale + view + origin × scale`；`buildCoordinateGrid` 把 `originX / originY` 折进基准点，后续视口范围、刻度与标签都按这个基准计算（`utils/canvasGrid.js`）。
- 原点取根节点 `x + controlX`、`y + controlY`（`gridOrigin`），也就是连接第一层子任务的出边按钮圆心。布局坐标仍以根节点左上角为基准，只有网格读数平移。
- 布局方向切到从右到左、根节点标题换行导致节点高度变化时，按钮位置改变，原点跟着移动；根节点没有子任务时按钮不显示，但该落点仍按同一公式计算，原点不会跳回左上角。

## 刻度与线条

- 主刻度由 `niceGridStep(spacing / scale)` 选出，只取 1/2/5×10ⁿ 并向上取整；默认目标间距 `spacing = 100`，因此屏幕上相邻主刻度不小于 100px，缩放时数值保持整齐（如 50、100、200、500、1000）。
- 细线是主刻度的 1/5，屏幕间距落在 20~40px；线条以整数下标生成，避免浮点累加漂移。下标是 5 的倍数时归入主刻度，下标 0 留给坐标轴，不重复画。
- 轴只在视口内绘制：`yAxis` 对应世界 x=0、`xAxis` 对应世界 y=0，都是原点在屏幕上的位置。
- 轴标签跳过 0；横向标签居中贴在 x 轴上方（轴太靠上缘时改到轴下方），纵向标签右对齐贴在 y 轴左侧，并在贴近视口边缘时夹回可见范围。
- 线段、轴刻度与标签全部在屏幕空间生成，因此平移缩放只改变位置，1~1.4px 线宽与 10px 字号不变。
- 网格层带 `pointer-events-none`，不参与节点点击、拖拽与滚轮判定；节点、连线画在它上层，网格不会盖住内容。

## 开关与持久化

| 键 | 默认 | 行为 |
| --- | --- | --- |
| `mindmap-coordinate-grid` | `false` | 右下角坐标按钮切换；打开时关闭点阵 |
| `mindmap-dot-grid` | `true` | 点阵按钮切换；打开时关闭坐标网格 |
| `mindmap-dark-canvas` | 跟随系统主题 | 画布底色；网格与标签在深色底上反相 |

- 两种底纹互斥：同为静态背景纹理，叠加会互相干扰，切换一个就关掉另一个（`toggleDotGrid`、`toggleCoordinateGrid`）。
- 配色集中在 `MindMapWrapper.vue` 的 `mindmap-grid-minor / -major / -axis / -label`，深色画布下换用白色透明度的同层次描边与填充。
- 三个键都走 `persistedRef`，存在 `todoheap:ui:` 前缀下；与任务数据、视图位置、应用主题互不影响。

## 边界

- 网格不读取任务内容，不改变布局、缩放范围或视图记忆。
- 坐标轴移出视口时只保留网格，不画没有落点的标签；没有指针坐标读数。
- 标签数值是世界坐标，不是 SVG 容器的像素坐标。
- 每次平移或缩放都会重算几何，但线条数量由视口尺寸和主刻度间距限制在百条量级，不需要节流。

## 关键落点

| 位置 | 作用 |
| --- | --- |
| `frontend/src/utils/canvasGrid.js` | 纯几何：视口换算、刻度取整、线条/轴/刻度/标签的位置 |
| `frontend/src/components/MindMapWrapper.vue` | SVG 网格层、`gridOrigin`、两个背景按钮、持久化键与配色 |
| `frontend/src/utils/canvasGrid.test.js` | 刻度取整、线条数量、标签跳过原点、轴移出视口、原点平移、零尺寸 |

## 验证

- 自动：`cd frontend && npx vitest run src/utils/canvasGrid.test.js`，覆盖刻度取整、主/细线位置、标签、轴可见性、原点平移与画布未测量。
- 手动：打开坐标网格后，坐标轴应穿过根节点出边按钮的圆心；切换布局方向，轴随按钮换到另一侧；平移让轴移出视口，标签消失而网格保留。
