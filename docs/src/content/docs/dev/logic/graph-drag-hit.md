# 任务图拖拽命中与空隙预览

本页说明拖节点时如何判定落点，以及「拖到父节点子级之间的空隙」如何命中父节点、如何预览。移动/链接写入规则见[视图与交互](../../features/views.md)，坐标与分层见[任务图布局逻辑](./mindmap-layout.md)。

---

## 一、命中顺序

1. **接触优先**：`linkTargetAtRect` 以影子矩形与节点矩形的间距判定，接触即命中；多个节点同时接触时取中心最近的。指针不必压在节点上。
2. **空隙命中父节点**：完全没有接触任何节点时，`findChildGapTarget`（`utils/mindmapDrag.js`）把父级可见子级列里的空白判给父级。
   - 候选按布局节点的 `parent_id`（树展开时的显示父级）分组；引用节点与占位节点不参与。
   - 子级列纵向范围 = 首子级上缘到末子级下缘；首/末外侧再放宽 `24 / scale` 屏幕像素（上限 48 图内单位），与按钮拉线的手感一致。
   - 影子必须与子级列横向重叠，避免把别层节点的空白误判给这个父级。
   - 槽位序号 = 影子纵向中心越过了几个子级中心；首端之前为 0，末端之后为子级数。
   - 相邻父级的接近范围重叠时取子级列中心更近的一个；被拖节点自己作为父级的子级列不参与。
   - 折叠父级没有可见子级，不产生空隙落点。

## 二、命中后的反馈

- 父级按「拖进节点」高亮（`isDropInside`）。
- `insertDropPlaceholder` 在父级子级列表的锚点位置插入虚节点：高度等于被拖节点（`dragState.sourceHeight`），布局按它真实让位；`dropPlaceholderNode` 用虚线框渲染。
- `dropPreviewLink` 用 `createEdge` 生成从父级到虚节点的曲线，以虚线强调色绘制，表示插入后的链接。
- 占位槽只参与渲染用的 `layout`；命中仍用不含占位槽的 `hitLayout`，避免目标被顶走后反复抖动。

## 三、提交的落点

- 松手时 `onDragEnd` 发出 `drop-task`：`parentId = 父级`、`position = 'inside'`、`insertBeforeId` / `insertAfterId` 为锚点直接子级。
- 锚点就是被拖节点自身时视为位置未变，不提交。
- `TodoGraph.vue` 的 `insertIntoParent` 分派：
  - 已是该父级子任务 → `moveTodo` 按锚点重排。
  - 多父任务 → 只在该父级 `child_ids` 的锚点位置加一条链接，提示可「改为移动（断开旧连接）」。
  - 单父任务 → `moveTodo` 移动到锚点位置；换父级时摘掉来源父链接。
- 顺序的最终依据仍是 `child_ids`，插入规则见[任务顺序](./task-order.md)。

## 四、验证

1. 展开一个有多个子节点的父级，子级间距较大时把另一个节点拖进空隙：父级高亮，空隙出现等尺寸虚线节点，父级到虚线节点有虚线。
2. 拖到父节点本体：仍按上/下四分之一前后插序、中间拖进，不走空隙规则。
3. 拖到首子级上方或末子级下方：接近范围内命中父级并插到首/末位，远离则不命中。
4. 拖到子节点本体：命中该子节点，显示原来的排序占位槽。
5. 折叠父级：不产生空隙落点。
