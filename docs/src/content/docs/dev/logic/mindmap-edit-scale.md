# 任务图编辑时的缩放档位

双击节点或按 F2 进入编辑时，画布会先把缩放抬到「编辑档位」，保证输入框里的字看得清；只在当前缩放更小时抬升，不会为了编辑而缩小。

## 实现

- `startEdit` 先取消待执行的居中（`cancelPendingCenter`）并停掉正在跑的视图动画，再设 `editingId` / `editingText`，最后调 `ensureEditScale(node)`。
- `ensureEditScale` 的目标值来自 `focusScale()`：`min(1.1, (focusWidth - 96) / nodeWidth)`，下限 0.15。`focusWidth` 用画布整宽（不扣右侧浮层），`nodeWidth` 固定 216；宽视口下就是 `FOCUS_SCALE = 1.1`（110%），画布窄到放不下节点时按可用宽度缩小。
- `view.scale` 已经不低于目标值时直接返回，所以 150% 下编辑不会掉回 110%，也不触发动画。
- 需要抬升时先退出三栏聚焦与根节点档位（`columnFocus = false`、`viewMode = null`），再经 `animateView` 缓动到目标缩放；x/y 由当前视口与节点中心反算，节点在屏幕上的位置保持不变，只以节点中心为锚点放大。
- 进入编辑态后节点随行数长高，见[节点文字折行与节点高度](./mindmap-text-wrap.md)；缩放档位与折行互不影响。

## 为什么是 1.1

编辑时的标准观看档位让节点主体约占视口宽度的 1/5，与选中节点的三栏聚焦共用 `FOCUS_SCALE` 上限。节点宽 216px 时，画布宽超过约 334px 就能到满 1.1；再窄才退让到刚好放得下节点。

## 验证

1. 全景缩放到 80% 后双击节点：画布平滑放大到 110%，节点不跳位，编辑框立即可输入；
2. 当前 150% 时双击：缩放不变；
3. 窄窗口（画布宽不足节点所需）双击：缩放按可用宽度缩小而不是固定 110%，节点不被裁切；
4. 正在执行自动居中时双击：居中动画被取消，输入框不会被移走。
