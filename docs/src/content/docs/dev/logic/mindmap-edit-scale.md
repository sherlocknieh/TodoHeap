# 任务图编辑时的缩放档位

双击节点或按 F2 进入编辑时，画布会先把缩放抬到与三栏聚焦相同的档位，保证输入框里的字看得清；只在当前缩放更小时抬升，不会为了编辑而缩小。

## 实现

- `startEdit` 先取消待执行的居中（`cancelPendingCenter`）并停掉正在跑的视图动画，再设 `editingId` / `editingText`，最后调 `ensureEditScale(node)`。
- `ensureEditScale` 的目标值直接取自 `columnFocusScale()`：`min(1.1, (focusWidth - 96) / (nodeWidth * 3 + mainGap * 2))`，即三栏视野（816px）在画布里的贴合档位。`focusWidth` 用画布整宽（不扣右侧浮层），宽视口封顶 `FOCUS_SCALE = 1.1`（110%），窄视口按三栏宽度缩小；编辑与选中聚焦共用这一个公式，不再按单节点宽度另算。
- `view.scale` 已经不低于目标值时直接返回，所以在三栏聚焦状态或 150% 下手动视角编辑都不改变缩放。
- 需要抬升时（自由视角且低于档位）退出三栏跟随（`columnFocus = false`、`viewMode = null`），再经 `animateView` 缓动到目标；x/y 由当前视口与节点中心反算，节点在屏幕上的位置保持不变，只以节点中心为锚点放大。已在档位之上时保持原状态，编辑结束后画布尺寸变化仍按三栏贴合。
- 进入编辑态后节点随行数长高，见[节点文字折行与节点高度](./mindmap-text-wrap.md)；缩放档位与折行互不影响。

## 为什么与聚焦同档

编辑要看清的是同一个节点，所以直接复用三栏聚焦的档位，避免同一节点在「选中」和「编辑」两个动作下出现两个缩放值：画布宽 ≥ 约 994px 时两边都是 110%；更窄时选中聚焦会缩到三栏可容纳的比例，编辑也停在同一比例，不再从约 86% 跳到 110%。编辑不参与三栏的居中重排，节点只在原位置放大，输入框不会被移走。

## 验证

1. 全景缩放到 80% 后双击节点：画布平滑放大到三栏档位（宽视口 110%，窄视口更小），节点不跳位，编辑框立即可输入；
2. 选中节点已按三栏聚焦后双击：缩放不变；
3. 当前 150% 时双击：缩放不变；
4. 窄窗口双击：编辑档位与选中聚焦一致，不会突然放大到 110%；
5. 正在执行自动居中时双击：居中动画被取消，输入框不会被移走。
