# 逻辑文档

本目录按机制记录系统当前的实现逻辑：链路怎么走、有哪些约束、如何验证。它回答「代码为什么这样写」，与[架构与技术栈](../architecture.md)的整体视角互补。

每篇只描述当前实现与约束；行为变化时直接改写对应段落，不保留旧实现与修复过程。需求与功能行为见[功能现状](../../features/index.md)。
