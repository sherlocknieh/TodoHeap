# 特性记录

本目录按功能域记录已经实现的需求：每条需求说明「要什么」，再记实现落点与结果。它回答「这个功能为什么存在、由哪条需求推动」，与[用户指南](../user/index.md)讲「怎么用」互补。

## 记录规则

- 本目录只记需求与功能；缺陷与修复不进这里，写入 `docs/zh/dev/logic/` 下对应的机制文档，讲清机制、根因与修正后的现状。
- 需求实现后立刻记入最贴近的篇目，不为单条需求另开新篇；确实没有合适篇目时再新建，并在下方索引登记。
- 一条需求一行：日期、需求原话（可精简）、实现要点、涉及文件或提交。
- 只记最新现状，不记历史：只描述当前实现，行为被后续需求改变时直接改写原条目。
- 功能删减不单独记录：把自定义行为恢复成默认值、移除某个功能时，删掉对应描述即可，不追加「已删除」「已还原」的条目，也不留历史痕迹。
- 不重复用户指南的操作步骤；需要展开说明时链接过去。
