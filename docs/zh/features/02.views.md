# 视图与交互

本页记录任务图、任务表、日程与堆视图的需求，含快捷键与复制粘贴。使用方式见[视图详解](../user/03.views.md)。

| 日期 | 需求 | 实现 |
| --- | --- | --- |
| 2026-11-18 | 节点右侧改用「更多操作」竖三点按钮，点击在按钮正下方展开菜单：重命名、新建子任务、复制为 Markdown、删除任务；取消原先的两段式删除确认 | 竖三点只在选中节点上显示，根节点没有；按钮悬停只加深图标，菜单打开时图标转绿。菜单是 HTML 浮层，`menuPosition` 按按钮圆心换算屏幕坐标并水平居中，下方空间不足翻到上方，左右再夹进画布；`MENU_ITEMS` 复用 `startEditById`、`createChild`、`copySubtreeAsMarkdown`、`emitDelete`，点画布、切换选中、滚轮或开始拖拽时收起。`frontend/src/components/MindMapWrapper.vue`、`components/AppIcon.vue`（新增 `moreVertical`） |
| 2026-11-18 | 节点悬停给出弱于选中的高亮：与选中同一个绿色、同样 2px 粗细，只靠透明度区分 | 节点 `g` 加 `group`，未选中且非拖拽落点的节点框用 `group-hover:stroke-2 group-hover:stroke-accent-600/45`；选中为 `stroke-2 stroke-accent-600` 加 `fill-accent-50`；暗色对应 `accent-400/45`。`frontend/src/components/MindMapWrapper.vue` |
| 2026-11-18 | 拖动节点时用影子节点可视化，不再拉线：指针处显示节点副本，原节点淡出；从折叠/加号按钮建链接仍保留拉线 | `MindMapWrapper.vue` 的 `dragState.shadow`/`grab`：按下时记录抓取点相对节点左上角的偏移，拖动中按偏移把源节点副本画在指针处（虚线强调色描边），`nodeOpacity` 让原件降到 0.3；`updateDrag` 在 `fromToggle` 分支外不再生成 `preview`，拉线与 `DRAG_ARROW_GAP` 只服务按钮建链接；落点高亮仍用 `targetId`，命中改由 `linkTargetAtRect` 按影子矩形与节点矩形是否接触判定，指针不必在节点上 |
| 2026-11-18 | 任务图拖拽落点按父级数量分派：单父任务优先移动，多父任务优先新增链接，并提示可改为移动；从折叠/加号按钮拉出的拖拽只建立链接 | 拖拽统一走 `drop-task` 事件；`TodoGraph.vue` 用 `findParentIds` 统计子任务父级，单个父级调 `moveTodo`（摘原父链接，成功后不弹提示），多个父级只追加 `child_ids`；按钮起点附带 `linkOnly`，无论父级数量都只链接。多父链接的提示带「改为移动（断开旧连接）」按钮，点了摘掉落点以外的所有父链接，也可撤销。轻提示扩展 `action`（标签 + 处理函数），与 `undo` 并列渲染。`frontend/src/pages/todo/TodoGraph.vue`、`pages/Todo.vue`、`components/MindMapWrapper.vue` |
| 2026-11-18 | Ctrl+C 复制节点和子节点（仅标题）为 Markdown 树状列表 | 任务图选中节点后按 Ctrl/Cmd+C，把该节点及全部后代标题输出为 `-` 列表，每层缩进两个空格；不受折叠影响，跳过 `isRef` 引用节点并按 `visited` 防环。剪贴板优先 `navigator.clipboard`，非安全上下文退回 `execCommand`；复制结果走既有 `notify` 轻提示。`frontend/src/components/MindMapWrapper.vue`、`TodoGraph.vue`（提交 0300394） |
| 2026-11-18 | 从折叠/展开/添加按钮拉出链接时，拉到目标节点附近即可命中，不必精确压在节点上 | 落点判定改为按矩形到节点矩形的间距计算，按钮拉线时被测矩形退化为指针点并外扩 24 屏幕像素（按缩放折算、上限 48 图内单位），多个节点同时命中取中心最近。`frontend/src/components/MindMapWrapper.vue` 的 `linkTargetAtRect` |
| 2026-11-18 | 按钮拉线时箭头要越过鼠标一小段，避免被指针图标盖住 | 预览线终点沿拉线方向再超出指针 18 屏幕像素（按缩放折算），箭头 tip 落在光标之外；只影响按钮拉线，节点拖拽已改为影子节点、不再画线。`frontend/src/components/MindMapWrapper.vue` 的 `DRAG_ARROW_GAP` |
| 2026-11-18 | 叶子节点的加号在指针靠近按钮位置时就显示，不必先进入节点；从加号拉线时按钮保持可见，不因指针移远而消失 | 画布指针移动时按到叶子控件中心 32 屏幕像素判定，命中即提前显示加号；拉线期间用 `draggingLeafId` 锁定源节点按钮，松手后再按指针位置重新判定；指针离开画布时清理。`frontend/src/components/MindMapWrapper.vue` 的 `updateLeafControlHover`、`LEAF_CONTROL_REVEAL` |
