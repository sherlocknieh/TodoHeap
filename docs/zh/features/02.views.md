# 视图与交互

本页记录任务图、任务表、日程与堆视图的需求，含快捷键与复制粘贴。使用方式见[视图详解](../user/03.views.md)。

| 日期 | 需求 | 实现 |
| --- | --- | --- |
| 2026-11-18 | 节点菜单：右侧竖三点按钮在悬停时即出现，节点上右键也能直接唤出菜单；菜单项为重命名、新建子任务、复制为 Markdown、删除任务 | 竖三点在选中、悬停（`hoveredNodeId`）或菜单打开时显示，根节点没有，拖拽中不显示；悬停只加深图标，菜单打开时图标转绿。节点 `g` 的 `contextmenu` 交给 `openNodeMenuAt`，不改变选中，只把指针位置换算成图内坐标存进 `menuAnchor`；`menuPosition` 让菜单从指针处展开并随缩放平移跟随，点按钮时仍贴在按钮正下方居中，空间不足翻到上方、右侧夹进 `visibleWidth`；原地编辑时放行浏览器右键菜单。`MENU_ITEMS` 复用 `startEditById`、`createChild`（按菜单所属节点建）、`copySubtreeAsMarkdown`、`emitDelete`，点画布、切换选中、滚轮或开始拖拽时收起。`frontend/src/components/MindMapWrapper.vue`、`components/AppIcon.vue` 的 `moreVertical` |
| 2026-11-18 | 节点悬停给出弱于选中的高亮：与选中同一个绿色、同样 2px 粗细，只靠透明度区分 | 节点 `g` 加 `group`，未选中且非拖拽落点的节点框用 `group-hover:stroke-2 group-hover:stroke-accent-600/45`；选中为 `stroke-2 stroke-accent-600` 加 `fill-accent-50`；暗色对应 `accent-400/45`。`frontend/src/components/MindMapWrapper.vue` |
| 2026-11-18 | 拖动节点用影子节点可视化：指针处显示节点副本，原节点淡出；只有从折叠/加号按钮建链接才拉线 | `MindMapWrapper.vue` 的 `dragState.shadow`/`grab`：按下时记录抓取点相对节点左上角的偏移，拖动中按偏移把源节点副本画在指针处（虚线强调色描边），`nodeOpacity` 让原件降到 0.3；`fromToggle` 分支生成 `preview`，其余拖拽不画线；落点高亮用 `targetId`，命中由 `linkTargetAtRect` 按影子矩形与节点矩形是否接触判定，指针不必在节点上 |
| 2026-11-18 | 任务图拖拽落点按父级数量分派：单父任务优先移动，多父任务优先新增链接，并提示可改为移动；从折叠/加号按钮拉出的拖拽只建立链接 | 拖拽统一走 `drop-task` 事件；`TodoGraph.vue` 用 `findParentIds` 统计子任务父级，单个父级调 `moveTodo`（摘原父链接，成功后不弹提示），多个父级只追加 `child_ids`；按钮起点附带 `linkOnly`，无论父级数量都只链接。多父链接的提示带「改为移动（断开旧连接）」按钮，点了摘掉落点以外的所有父链接，也可撤销。轻提示支持 `action`（标签 + 处理函数），与 `undo` 并列渲染。`frontend/src/pages/todo/TodoGraph.vue`、`pages/Todo.vue`、`components/MindMapWrapper.vue` |
| 2026-11-18 | Ctrl+C 复制节点和子节点（仅标题）为 Markdown 树状列表 | 任务图选中节点后按 Ctrl/Cmd+C，把该节点及全部后代标题输出为 `-` 列表，每层缩进两个空格；不受折叠影响，跳过 `isRef` 引用节点并按 `visited` 防环。剪贴板优先 `navigator.clipboard`，非安全上下文退回 `execCommand`；复制结果走既有 `notify` 轻提示。`frontend/src/components/MindMapWrapper.vue`、`TodoGraph.vue`（提交 0300394） |
| 2026-11-18 | 任务图下右侧栏始终浮在画布上，不挤压导图宽度；右下角视图控件跟着面板左移，不被遮挡 | 任务图渲染一个 `absolute inset-0 flex` 的透明浮层：左侧空白区只占位、右侧放 `TodoDetailEditor`，面板浮在画布上而不改变画布宽度。视图控件留在画布内，按共享的右栏宽度用 `calc(0.75rem + inset)` 左移，面板拖宽时跟随。浮层右栏点击面板外收起，画布内的点选由导图自己处理。导图另按共享的 `detailPanelInset` 算可见宽度，把选中节点聚焦、适应视图与节点更多菜单定位限制在面板左侧，避免三点按钮被浮层压住。`frontend/src/pages/Todo.vue`、`components/MindMapWrapper.vue`、`utils/detailPanelContext.js` |
| 2026-11-18 | 从折叠/展开/添加按钮拉出链接时，拉到目标节点附近即可命中，不必精确压在节点上 | `linkTargetAtRect` 按矩形到节点矩形的间距判定，按钮拉线时被测矩形退化为指针点并外扩 24 屏幕像素（按缩放折算、上限 48 图内单位），多个节点同时命中取中心最近。`frontend/src/components/MindMapWrapper.vue` |
| 2026-11-18 | 浮起的侧栏与右栏在点击外部时收起，画布空白点击也算外部 | `MindMapWrapper` 的点击会阻止冒泡，外部点击监听收不到；因此画布空白点击额外发出 `background-click`，经 `TodoGraph` 转给 `Todo.vue` 的 `handleCanvasBackgroundClick`，收起浮层导航与详情右栏。任务图里选中节点同样收起浮层导航，避免挡住画布。`frontend/src/pages/Todo.vue`、`pages/todo/TodoGraph.vue`、`components/MindMapWrapper.vue` |
| 2026-11-18 | 按钮拉线时箭头越过鼠标一小段，避免被指针图标盖住 | 预览线终点沿拉线方向再超出指针 18 屏幕像素（按缩放折算），箭头 tip 落在光标之外；节点拖拽走影子节点、不画线，因此只作用于按钮拉线。`frontend/src/components/MindMapWrapper.vue` 的 `DRAG_ARROW_GAP` |
| 2026-11-18 | 叶子节点的加号在指针靠近按钮位置时就显示，不必先进入节点；从加号拉线时按钮保持可见，不因指针移远而消失 | 画布指针移动时按到叶子控件中心 32 屏幕像素判定，命中即提前显示加号；拉线期间用 `draggingLeafId` 锁定源节点按钮，松手后再按指针位置重新判定；指针离开画布时清理。`frontend/src/components/MindMapWrapper.vue` 的 `updateLeafControlHover`、`LEAF_CONTROL_REVEAL` |
| 2026-11-18 | 聚焦节点只做水平居中，纵向留在原来的屏幕位置；纵向布局的三栏仍垂直居中 | 抽出 `focusTargetFor` 供聚焦动画与尺寸重贴合共用：纵向布局的三栏沿高度排列，垂直居中；横向布局沿用节点当前屏幕纵向位置，节点整体将移出视口时按节点半高加 24 像素边距夹回可见范围。`frontend/src/components/MindMapWrapper.vue` 的 `focusTargetFor`、`centerOnNode`、`followColumnFocus` |
| 2026-11-18 | 节点原地编辑时，节点框随输入行数长高，不出现内部滚动条 | 编辑中的节点由 `measureNode` 按 `editingText` 折行且不设行数上限，节点框高度、`foreignObject` 高度与文字行数同源，输入时整图随之重排，输入框始终与内容等高；`editingId`/`editingText` 定义在布局计算之前供测量读取。`frontend/src/components/MindMapWrapper.vue` |
| 2026-11-18 | 节点原地编辑支持 Shift+Enter 手工换行，单独回车仍然提交 | `onEditKeydown` 放行 Shift+Enter 交给输入框默认行为；`wrapLines` 把 `\n` 当硬换行，空白行也占一行，节点高度因此同步；`commitEdit` 只压缩行内空白、保留换行并去掉首尾空行；复制为 Markdown 时把换行压成空格，避免打断列表。`frontend/src/components/MindMapWrapper.vue` |
