# 视图详解

工作区左侧栏的「视图」分组提供三个入口：任务图、任务表、回收站，其中任务图是默认视图。堆视图的路由仍然保留，但侧栏入口已隐藏。

左侧活动栏另有「清单 / 日程 / AI」三个主入口，每个入口对应一套侧栏内容：清单展示视图入口，日程展示日程概览，AI 展示优化操作与模型入口。点击当前入口收起或展开侧栏，点击其他入口则切换视图并展开对应侧栏。活动栏顶部的 Logo 点击可回到主页；底栏左侧的开关会把活动栏与侧栏整体收起以腾出空间，再次点击开回并恢复原来的侧栏状态。

每个视图的顶栏右侧都有同一个右栏开关，打开后承载该视图自己的内容：任务表、任务图、堆与回收站是任务详情，日程是选中日程的详情，AI 是对话上下文。

左侧栏与右侧面板都可以拖动内侧边缘调整宽度，宽度会记住；拖到最小宽度后继续拖动一小段才收起该面板。

## 视图对比

| 视图 | 形态 | 适合 |
| --- | --- | --- |
| 任务图（默认） | 思维导图式任务图 | 梳理结构、批量调整层级 |
| 任务表 | 线性清单，支持多级缩进 | 日常增删改、按顺序推进 |
| 回收站 | 已删除任务的列表 | 找回误删任务 |
| 堆视图（入口隐藏） | 按优先级排序的执行队列 | 决定下一个做什么 |
| AI Agent | 对话式管理任务、日程与偏好 | 复杂增删改、批量整理 |
| 日程 | 日历事件按日期分组 | 看接下来几天有哪些日程 |

## 任务表

从侧栏「视图」进入，适合逐条编辑。

### 界面结构

- 主区域顶栏统一显示当前视图标题；任务表的顶栏右侧是进度（待办 / 已完成数量）、排序方式与多选入口
- 顶栏下方是整行可聚焦的添加框，写标题回车即存
- 任务按层级缩进排列，默认展开前两层；父任务左侧的箭头可以折叠/展开子任务
- 已完成的任务收在列表末尾的「已完成」区域，没有已完成任务时不占位置
- 单击任务会在右侧打开详情面板
- 页面底部的输入栏用一句话描述任务，交给 AI 拆解

### 常用操作

| 操作 | 方式 |
| --- | --- |
| 新增任务 | 顶部输入框写标题，回车 |
| 添加子任务 | 任务行「更多」菜单 → 添加子任务 |
| 完成 / 取消完成 | 任务行左侧复选框 |
| 重命名 | 双击标题，回车保存，Esc 取消 |
| 查看与编辑详情 | 单击任务行 |
| 设置截止时间 | 任务行右侧的日历按钮（未设时间时）或截止时间标签，可选今天、明天、本周末或自定义时间 |
| 排序 | 工具栏的排序下拉框 |
| 多选与批量操作 | 工具栏「选择」，底部操作条处理选中任务 |
| 调整顺序与层级 | 拖拽任务行 |
| 删除 | 任务行「更多」菜单 → 删除任务，进入回收站 |

任务行的操作按钮常驻显示：日历按钮或截止时间标签负责设置时间，「更多」菜单收着添加子任务与删除。

### 排序

工具栏可在手动顺序、截止时间、创建时间、难度之间切换，排序只重排同级任务，子任务跟着父任务走并各自排序。

排序方式属于显示偏好，保存在本机；「手动顺序」才是拖拽调整后写回数据的真实顺序。

### 拖拽调整

- 拖到另一行的上边缘或下边缘：插到该任务前面或后面，成为同级
- 拖到另一行的中间：成为该任务的子任务
- 拖拽会真正修改父子关系与顺序，刷新后仍然生效

不能把任务拖进自己或自己的子任务里，拖拽时会被拒绝并提示原因。

### 多选批量操作

点击工具栏「选择」进入多选模式，每行左侧变成勾选框。底部操作条支持：

| 操作 | 说明 |
| --- | --- |
| 标为完成 / 取消完成 | 只处理未完成（或已完成）的选中任务 |
| 设置截止时间 | 今天、明天、本周末或清除 |
| 删除 | 连同子任务一起移入回收站，操作前会确认 |

父子任务同时选中时只处理父任务，避免重复级联。

### 操作反馈与撤销

删除任务、切换完成状态、批量操作后，底部会出现提示条。带「撤销」的提示在几秒内可点撤销，撤销同样会同步到服务器。

## 任务图

打开应用后的默认视图。用思维导图展示同一张任务图，适合先理清结构再逐条执行。

### 界面结构

- 导图占满活动栏以外的区域，底栏保留导航开关、统计开关与同步状态；侧栏可随时打开，以浮层覆盖导图，开关侧栏不会移动导图
- 每个任务只出现一次，所有父引用都画成连线，环用回边绕回表示
- 右上角的方向按钮循环切换布局方向：从上到下、从左到右、从下到上、从右到左，默认从左到右
- 根节点为「全部任务」，按所选方向分层展开
- 单击节点选中任务；顶栏右栏开关可在右侧打开该任务的详情，侧栏以浮层覆盖导图时不影响布局
- 滚轮缩放、拖拽平移、双击画布或点右下角「适应视图」按钮复位

### 拖拽建立链接

按住一个节点拖到另一个节点上松开，即把源任务链接为目标任务的子任务，形成多父关系；源任务原有的父级不变。

- 拖动时从源节点拉出虚线预览，落点节点高亮表示可以链接
- 链接成功后底部提示条可撤销，撤销只移除这条新链接
- 目标已经是源任务的子任务、或目标在源任务的子树里（会成环）时会被拦截并提示
- 回边节点只是引用，不能作为拖拽起点或落点

### 键盘操作

选中节点后画布获得焦点，可直接用键盘增删改：

| 按键 | 作用 |
| --- | --- |
| `Enter` | 新建同级任务，插在当前节点之后并立即进入重命名 |
| `Tab` | 新建子任务，挂到当前节点下并立即进入重命名 |
| `F2` / 双击节点 | 重命名当前节点，`Enter` 保存、`Esc` 取消 |
| `Delete` / `Backspace` | 删除当前节点及其子任务，底部提示条可撤销 |
| `Space` | 切换完成状态 |
| 方向键 | 沿布局方向移动：主方向进入子级或回到父级，交叉方向在同级之间切换 |
| `Esc` | 取消选中 |

方向键的含义跟随布局方向，例如从左到右时 `→` 进入子级、`←` 回到父级、`↑` `↓` 切换同级。回边节点只是引用，不能直接重命名或删除，选中后会跳到被引用的真实任务。

## 回收站

删除的任务先进入回收站，可恢复或彻底清除。

### 操作

- 未选中任务时，头部提供「恢复全部」「清空」
- 单击某条任务后，头部按钮变为针对该任务的「恢复」「永久删除」

### 恢复限制

父子任务必须按顺序恢复：父任务仍在回收站里时，直接恢复子任务会被拦截，并提示先恢复父任务。这样可以避免出现没有父级的孤立节点。

## 堆视图

按优先级得分从高到低排列任务，左侧是堆结构可视化，右侧是排序后的列表。节点颜色对应优先级等级，数字为得分。

::: tip 入口说明
堆视图目前没有侧栏入口，可直接访问 `/app/heap` 查看。
:::

## 日程

从活动栏的日程入口进入，按日期排列 `schedules` 里的日历事件，任务不会出现在这里：

- 今天、明天优先，其余按日期升序
- 同一天的事件按开始时间排序，显示时间区间
- 整日事件标为「全天」
- 单击事件行会在右侧打开该日程的详情，标题、起止时间与备注可直接修改，保存后写回 `schedules`
- 详情面板底部的「删除」可以移除该日程，换选其他事件时草稿跟着切换，不会带到另一条日程

右上角提供「导入 / 导出 / 订阅」三个入口：导入 `.ics` 日历、导出日程文件、跳转到设置页管理订阅链接。详见 [日历导入导出与订阅](./06.calendar.md)。

查看任务请使用任务表或任务图。

## AI Agent

从活动栏的 AI 入口进入，这里是一个对话式 Agent：

- 用一句话描述需求，Agent 会调用工具读取或修改任务与日程
- 拆解、新建、优化都在对话里完成，清单视图不再有单独的 AI 按钮
- 左侧侧栏管理会话，模型在「设置 → 模型接入」中配置
- 删除、清空回收站等破坏性操作会先弹出确认

详见 [AI 智能功能](./02.ai-features.md)。

## 视图切换

点击左侧栏「视图」分组中的条目即可切换；窄屏下切换后侧栏会自动收起。

视图与路由一一对应：

| 视图 | 路由 |
| --- | --- |
| 任务图 | `/app/graph` |
| 任务表 | `/app/list` |
| 回收站 | `/app/trash` |
| 堆视图 | `/app/heap` |
| 日程 | `/app/schedule` |
| AI Agent | `/app/ai` |
