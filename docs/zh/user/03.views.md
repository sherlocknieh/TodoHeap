# 视图详解

工作区左侧栏的「视图」分组提供三个入口：列表、树视图、回收站。堆视图的路由仍然保留，但侧栏入口已隐藏。

左侧活动栏另有「清单 / 日程 / AI」三个主入口：清单进入列表视图，AI 进入 AI 工作台，日程为占位入口、暂未开放。

## 视图对比

| 视图 | 形态 | 适合 |
| --- | --- | --- |
| 列表视图 | 线性清单，支持多级缩进 | 日常增删改、按顺序推进 |
| 树视图 | 思维导图式任务树 | 梳理结构、批量调整层级 |
| 回收站 | 已删除任务的列表 | 找回误删任务 |
| 堆视图（入口隐藏） | 按优先级排序的执行队列 | 决定下一个做什么 |
| AI 工作台 | 自然语言建任务 + 全局优化入口 | 批量生成、重排任务 |

---

## 列表视图

打开应用后的默认视图。

### 界面结构

- 顶部一行快速添加
- 任务按层级缩进排列，父任务左侧的箭头可以折叠/展开子任务
- 已结束的任务收在底部「已完成」区域，可整体收起
- 单击任务会在右侧打开详情面板

### 常用操作

| 操作 | 方式 |
| --- | --- |
| 新增任务 | 顶部输入框写标题，回车 |
| 添加子任务 | 任务行右侧的「+」 |
| 完成 / 取消完成 | 任务行左侧复选框 |
| 重命名 | 双击标题，回车保存，Esc 取消 |
| 查看与编辑详情 | 单击任务行 |
| AI 分解 | 任务行「更多」菜单 → AI 分解 |
| 删除 | 任务行「删除」按钮，进入回收站 |

任务的悬停操作在触屏设备上始终可见，在桌面端悬停才出现。

---

## 树视图

用思维导图展示同一棵任务树，适合先理清结构再逐条执行。

### 界面结构

- 画布中央是整棵任务树，根节点为「全部任务」
- 选中任一节点，右侧同时打开该任务的详情面板
- 画布右下角的「适应视图」按钮把整棵树缩放到可见范围

### 编辑方式

编辑节点文字、插入节点、删除节点都会写回任务数据，与列表视图保持一致：

| 操作 | 效果 |
| --- | --- |
| 修改节点文字 | 更新任务标题 |
| 插入节点 | 在对应位置新增子任务 |
| 删除节点 | 任务进入回收站 |

节点数量较多时，画布渲染会变慢，此时可以先在列表视图整理结构。

---

## 回收站

删除的任务先进入回收站，可恢复或彻底清除。

### 操作

- 未选中任务时，头部提供「恢复全部」「清空」
- 单击某条任务后，头部按钮变为针对该任务的「恢复」「永久删除」

### 恢复限制

父子任务必须按顺序恢复：父任务仍在回收站里时，直接恢复子任务会被拦截，并提示先恢复父任务。这样可以避免出现没有父级的孤立节点。

---

## 堆视图

按优先级得分从高到低排列任务，左侧是堆结构可视化，右侧是排序后的列表。节点颜色对应优先级等级，数字为得分。

::: tip 入口说明
堆视图目前没有侧栏入口，可直接访问 `/app/heap` 查看。
:::

---

## AI 工作台

从活动栏的 AI 入口进入，把 AI 能力收在一处：

- 顶部输入框用一句话描述目标，AI 会拆成可执行的任务
- 下方「开始优化」让 AI 按当前清单重新排序，并修正重复或含糊的任务
- 分解与优化的进度显示在页面上方，确认后任务写入清单

---

## 视图切换

点击左侧栏「视图」分组中的条目即可切换；窄屏下切换后侧栏会自动收起。

视图与路由一一对应：

| 视图 | 路由 |
| --- | --- |
| 列表 | `/app/list` |
| 树视图 | `/app/tree` |
| 回收站 | `/app/trash` |
| 堆视图 | `/app/heap` |
| AI 工作台 | `/app/ai` |
