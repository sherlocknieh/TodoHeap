# 用户指南

TodoHeap 是一个把"想做的事"变成"能立刻做的事"的任务管理工具：AI 负责拆解和排序，你只负责执行。

## 快速开始

访问 [TodoHeap 应用](https://sherlocknieh.github.io/TodoHeap/) 注册账户即可使用：

- **注册**：邮箱注册新账户
- **登录**：邮箱 + 密码
- **重置密码**：忘记密码时通过邮件重置

## 核心概念

### 完成状态

任务只有"未完成"与"已完成"两态，由完成时间（`completed_at`）是否为空判定。勾选后收进底部「已完成」区域，取消勾选即恢复为待办。

删除的任务进入回收站，可恢复或永久删除。

### 优先级

优先级不是手动填写的字段，而是系统按截止紧迫度、完成进度与子任务复杂度实时算出的得分。堆视图按得分从高到低排列，并用颜色区分等级。

日常不必维护优先级：把截止时间与预估工时填准，剩下的交给排序。
