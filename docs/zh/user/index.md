## 核心概念

### 任务状态

- **待办** (todo)：新创建或未开始
- **进行中** (doing)：正在执行
- **已完成** (done)：已完成的任务
- **已删除** (deleted)：删除的任务，可从垃圾箱恢复

### 优先级

系统自动计算，但也支持手动调整：
- **0** = 低优先级
- **1** = 中优先级  
- **2** = 高优先级
