# AI 智能功能

TodoHeap 只有一个 AI 入口：AI 视图里的对话 Agent。拆解、建任务、优化、日程安排都在对话里完成，不再有分散的 AI 按钮。Agent 能读写当前用户的任务（含回收站）、日程，以及应用设置。

## 对话 Agent

直接用一句话描述需求，Agent 会调用工具读取或修改数据，并在对话里展示每一步操作。例如：

| 你说 | Agent 会做 |
| --- | --- |
| "这周有哪些任务快逾期了？" | 按截止时间筛选未完成任务并给出建议 |
| "把「准备季度汇报」拆成 5 个子任务，下周五前完成" | 创建任务树并写入截止时间 |
| "把「写提纲」挪到「季度汇报」下面" | 调整任务层级 |
| "帮我建一条明天 15:00-16:00 的评审会日程" | 新建日程事件 |
| "帮我做一次全局任务优化" | 按内置指令整理日期、拆解、聚合并给出执行建议 |

每条用户消息下方都有「查看请求」入口，展开后能看到这一轮实际发给模型的全部提示词：系统提示、历史消息、工具结果、可用工具与模型参数。一次回复可能包含多次请求，会按顺序逐条列出。这些记录只保留在当前页面，刷新后不再显示。

### 输入区

输入框下方常驻一条工具条，不用离开对话就能切换模型和工作模式：

| 操作 | 说明 |
| --- | --- |
| + | 鼠标入口：图片和文件、挂载技能、引用任务或日程 |
| 模型 | 点开列出当前服务商的型号（内置模式为网关返回的列表），选中即生效；底部可跳到模型接入设置 |
| 图片 | 选择本地图片，也可以直接粘贴截图或把文件拖进输入框；每条消息最多 4 张，支持 PNG / JPEG / WebP / GIF，单张不超过 10MB，长边会压到 1280px |
| 发送 / 停止 | 生成中按钮变为「停止」，也可以按 Esc 中断 |
| 快捷键 | Enter 发送，Shift+Enter 换行，Ctrl/Cmd+Enter 也可发送 |

输入框会随内容自动增高，草稿按会话分别保存，切换会话不会互相覆盖。

### 工作模式

输入区工具条上的模式按钮切换工作模式，模式跟随会话保存，新会话默认只读模式：

| 模式 | 工具范围 |
| --- | --- |
| 只读模式 | 只读：查看任务、读取任务、回收站、日程、应用设置 |
| 全能模式 | 全部工具，可读写任务、日程与设置 |
| 清单读写 | 只管理任务清单与回收站 |
| 日程读写 | 只管理日程事件 |

每个模式都额外带 `switch_mode`，受限模式可以请求放开权限。模式只发送本域工具，其余工具 schema 与规则不占 token，适合先讨论方案再动手。Agent 可以调用 `switch_mode` 请求切换：方案与切换请求在同一条回复里发出，确认卡片随方案一起出现，确认后本轮后续请求立即按新模式发送工具，不必再补发一条消息。从只读模式切出只是临时放开权限：本轮正常结束后会自动回到只读模式，用户取消提问、模型出错或撞上步数上限时保留新模式，方便接着处理；在界面上手动切换的模式不受影响。

需要用户拍板时（确认方案、选时间、选对象、二选一），Agent 会调用 `ask_user` 给出 2-6 个可直接执行的选项，输入框上方弹出选择面板，点一下即作为答复返回，本轮继续执行；点「跳过」则把取消结果交回模型。所有模式都保留这个入口。

工具范围只通过请求的 `tools` 字段下发，不再重复写进消息。右侧栏「上下文」按系统提示、可用工具、对话消息、工具输出四类统计占比；下方「可用工具」先列请求参数（model / temperature / stream / tool_choice），再列各工具定义，「请求消息」按实际发送顺序展示全部消息，最底部可展开查看完整请求体。

### 思考等级

输入区模型选择右侧的「思考等级」控制思考强度，共三档，默认「关闭」，浮层从高到低排列：

| 等级 | 行为 |
| --- | --- |
| 高 / 低 | 原样作为 `reasoning_effort` 下发，等级越高推理越深、耗时越长 |
| 关闭 | DeepSeek 系模型下发 `thinking: { type: "disabled" }` 走非思考模式；其它服务商不发思考参数 |

模型返回思考内容时（`reasoning_content` / `reasoning` / `thinking` 任一字段）会显示在回复上方的「思考过程」折叠块里，默认收起，正文优先；上游不遵守关闭参数时，内容照常展示。右侧栏「请求参数」会同步展示实际下发的 `reasoning_effort` 或 `thinking`。多轮对话里上一轮的思考内容会以 `reasoning_content` 原样回传，满足 DeepSeek 等服务的校验要求。右侧栏「本轮上下文」按会话实时消息统计，模型刚产出的回复也会计入；带思考的消息标注「含思考」并显示思考字符数，展开可见完整 `reasoning_content`。

### 命令与引用

三个入口各管一件事，不重叠：

| 入口 | 语义 | 内容 |
| --- | --- | --- |
| `/` | 执行一个动作 | 添加图片和文件、挂载技能、引用任务或日程、新建会话、清空对话、切换模型、模型接入设置 |
| `@` | 引用一个对象 | 任务与日程，按类型分组；选中后成为输入框上方的引用标签，可逐个移除 |
| `+` 菜单 | 挂载或引用 | 图片和文件、技能、任务或日程；技能选中后成为输入框上方的标签，指令随本轮消息发送 |

`@` 只引用数据对象，技能属于「挂载指令」而不是「引用对象」，因此不放进 `@` 列表；技能指令写进本轮系统提示，发送后标签清空。引用的任务与日程会写进本轮系统提示（含 id 与标题），模型不必再猜「这个任务」指谁；引用只作用于这一轮，发送后清空。`+` 菜单是鼠标入口，与 `/`、`@` 选择器互斥，不会叠在一起。

图片按 OpenAI 多模态格式随消息发送，需要所选模型支持视觉输入。图片本体只存在本机 IndexedDB，不会上传到 TodoHeap 的存储；会话记录里只保留尺寸等元数据，刷新后自动恢复。点击缩略图可查看大图，点背景或按 Esc 关闭。

### 消息操作

鼠标移到消息上会出现操作按钮（触屏设备常驻显示）：

- 用户消息：复制、编辑并重新发送。编辑重发会截断这条消息之后的内容，用新文本重新请求。
- Agent 回复：复制、重新生成、删除。重新生成只对最后一条回复生效。
- 出错时错误提示右侧提供「重试」，直接重发上一条消息。

向上翻阅历史时，流式输出不会把视图拽回底部；需要时点右下角的回到底部按钮。

## 让 Agent 改设置

Agent 可以直接修改应用设置，改完即时生效，不必刷新页面：

| 类别 | 可改内容 |
| --- | --- |
| 界面偏好 | 任务图布局方向、左侧栏与活动栏开关、详情面板开关、列表是否显示已完成 |
| 模型参数 | temperature（0–2） |
| 技能 | 新建、修改、删除 |
| 日历订阅 | 重置令牌、关闭订阅 |

改设置前 Agent 会先调用 `list_app_settings` 确认键名与当前值；重置或关闭日历订阅、删除技能属于破坏性操作，会先弹确认框。模型服务商、Base URL、API Key、账户密码与账号本身不开放给 Agent，需要本人到设置页操作。

## 对话上下文面板

AI 视图右侧可以打开「对话上下文」面板，单页展示这一轮对话的输入构成：

| 区块 | 内容 |
| --- | --- |
| 请求参数 | model、temperature、stream 等协议字段的两列键值，点标题右侧的图标展开原始 JSON |
| 上下文构成 | 按系统提示、工具定义、思考消息、工具调用、工具输出、对话消息拆分的字符占比与估算 token，思考与工具调用附数量 |
| 工具定义 | 本次请求实际提供的工具，展开可看完整 schema |
| 本轮上下文 | 模型真正收到的全部消息，逐条带内容摘要（工具调用显示为「调用 查看任务」），展开看完整 JSON |
| 完整请求体 | 参数、工具、消息按序排列的原始 body，标题右侧可直接导出当前会话 |

上下文数据取自最近一次真实请求，不是本地估算的对话内容；请求快照只在当前页面保留，刷新后「最近一次请求」为空属正常。面板宽度可拖拽，与其他视图的任务详情面板互不影响。

## 多会话

对话按会话保存，不同话题互不干扰：

- 左侧 AI 侧栏展示会话列表，可新建、切换、重命名或删除会话
- 新会话的标题由第一条消息自动生成
- 会话只保存在本机浏览器；切换账号会加载各自的会话
- 旧的单会话记录会自动迁移成一个带标题的会话

## 接入第三方模型

1. 打开 **设置 → 模型接入**
2. 选择服务商预设：OpenAI、DeepSeek、Kimi、智谱 GLM、阿里百炼、Google Gemini、OpenRouter、本地 Ollama，或选择"自定义"
3. 填写 Base URL、模型名称与 API Key（本地模型可留空）
4. 点击"测试连接"确认可用

配置保存在本机浏览器，不会上传到服务器；换设备需要重新填写。服务商需要允许浏览器直连（CORS），否则请改用支持该能力的服务商或自建代理。

## 使用内置模型

不想自己准备密钥时，在 **设置 → 模型接入** 切换到「内置模型」。模型列表由网关返回：优先使用平台配置的白名单，否则查询上游服务商的模型列表；读取失败时可以手动填写。请求会经 TodoHeap 网关转发到平台配置的模型服务，用量与订阅状态由服务端掌握。

> 当前为网关骨架：订阅与额度校验尚未启用，所有已登录用户都可以调用。接入计费后，未订阅或额度用尽的请求会返回 402/429。

## 技能管理

技能就是一段写给 Agent 的固定指令，保存后可以从左侧 AI 侧栏挂到本轮对话上：

- 侧栏「技能」区列出全部技能，点击技能名进入编辑；行尾的 + 把技能挂到输入框上方，指令随本轮消息一起发送；输入框 + 菜单里的「挂载技能」提供同样的入口
- 技能区高度可以拖拽上缘调整
- 右上角 + 新建技能：填写名称、挑一个图标、写下指令即可
- 可指定技能绑定的工作模式；挂载技能会同时切到该模式，选「跟随会话」则沿用当前模式
- 删除收在编辑表单里，只有编辑已有技能时才出现
- 技能保存在账号的 `user_settings` 里，换设备登录后依旧可用

默认自带「全局任务优化」技能，对应对话里说的「帮我做一次全局任务优化」，Agent 会：

| 操作 | 说明 |
| --- | --- |
| 调整日期 | 让截止时间落在合理的先后顺序上 |
| 拆解 | 把过于笼统的任务拆成子任务 |
| 聚合 | 把重复或过碎的条目合并 |
| 生成执行建议 | 标出建议先做的那一条 |

内置技能同样可以编辑或删除；它和其他技能一样，只是给 Agent 的一段指令，不是独立功能。

## MCP 服务

Agent 除了内置的任务、日程与设置工具，还能接入外部 MCP 服务（Model Context Protocol），把对方提供的工具直接挂进同一轮对话：

- 内置一键添加：点「滴答清单」会先打开填好地址的表单，确认后保存；缺授权时在**新标签页**打开滴答登录，原页面不会跳走，授权完成后服务自动出现
- 左侧 AI 侧栏「MCP 服务」分组右上角 + 新建：填服务名称、MCP 地址（通常是 `https://…/mcp`）和可选访问令牌，保存后立即握手并拉取工具列表
- 列表里显示工具数量；连不上时把失败原因直接写在服务名下，例如令牌失效或地址不可达
- 行尾有开关与删除按钮：开关控制启停，停用后配置保留但工具不再发给模型；删除会清掉该服务的配置与会话
- 删除内置的滴答清单需要点两次确认：它同时会断开「设置 → 导入数据」里的滴答授权，下次添加要重新登录
- 悬停服务行还能看到重新连接（刷新工具列表）与内置服务的重新授权（钥匙图标，授权完成会回到 AI 视图）
- 点击服务名进入编辑，删除按钮收在编辑表单里
- 工具名统一带 `mcp__服务名__工具名` 前缀，展示时还原为「服务 / 工具」；不同服务里有同名工具也不会冲突

外部工具是否可写由服务自己声明：标注了只读的工具可以直接调用，其余工具调用前会弹出确认卡片，说明参数会发往你配置的外部地址。只读模式下只保留声明只读的外部工具，因此不会在只读模式里写数据。

MCP 服务配置（含令牌）只保存在本机浏览器，并按账号分开存放；换设备或换浏览器需要重新配置。浏览器直连第三方 MCP 常被跨域拦住，MCP 请求都经 Supabase 边缘函数 `mcp_gateway` 转发（滴答清单也一样）。滴答的登录授权另由 `dida_auth` 代理，只做注册客户端与换令牌。两个网关都不落库任何令牌。

如果服务名下出现 `Failed to fetch` 或「请确认边缘函数已部署」，说明请求没有到达服务端：先执行 `supabase functions deploy mcp_gateway`，再点行尾的重新连接。

## 破坏性操作

删除任务、清理已完成、永久删除和清空回收站会先弹出确认，确认后才会执行。可以让 Agent 先说明影响再决定。

## 常见问题

### Q: 如何拆解已有任务？

直接说「把某个任务拆成几个子任务」，Agent 会找到对应任务并创建子树。也可以先问「我有哪些任务」，再在后续消息里指代具体任务。

### Q: 如何用一句话新建任务？

直接说目标即可，例如「下周准备季度汇报」。Agent 会判断是否拆成任务树并补齐截止时间。

### Q: 模型不可用怎么办？

检查 Base URL、模型名与密钥，或在设置里点「测试连接」。内置模型不可用时，确认 `llm_gateway` 已部署且平台密钥已配置。

### Q: 会话会上传吗？

会话保存在本机浏览器。只有你发送的消息与工具结果会发给所选模型服务；内置模式会经过 TodoHeap 网关。
