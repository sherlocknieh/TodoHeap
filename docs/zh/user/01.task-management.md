# 任务管理详解

本文详细说明如何在 TodoHeap 中创建、编辑、删除任务。

## 任务属性详解

### 基础属性

| 属性 | 说明 | 必需 |
|-----|------|------|
| **标题** | 任务的名称或描述 | ✅ |
| **状态** | 待办/进行中/已完成/已删除 | 默认 todo |
| **优先级** | 0（低）、1（中）、2（高） | 自动计算 |
| **截止日期** | 任务的完成期限 | 可选 |
| **难度** | 完成任务的预估工作量 | 可选 |
| **描述** | 任务的详细说明 | 可选 |

### 任务状态流转

```
┌─ 待办 (todo)
│    ↓
│    ├→ 进行中 (doing) ──→ 已完成 (done)
│    ↓
└─ 已删除 (deleted) ──→ 恢复为待办
```

## 创建任务

### 快速创建

**最简单的方式**：在任意输入框输入任务名称，按 Enter 或点击「创建」

```
输入：「完成报告」
按 Enter
↓
任务立即创建，状态为 待办
```

### AI 智能创建

需要自动分解任务？使用 **AI 任务分析** 功能。

输入详细描述（如"下周要完成项目提案"），系统自动分析、分解为多个子任务并直接入库。

详见 [AI 智能功能 - AI 任务分析](./ai-features.md#ai-任务分析)

## 编辑任务

### 打开详情编辑器

在任意视图中点击任务，右侧面板弹出详情编辑器。

### 编辑字段

#### 标题与描述

- **标题**：修改任务名称（必填）
- **描述**：添加任务详细说明、备注等（可选）
- 支持 Markdown 格式编辑

#### 状态管理

快速切换任务状态：

- `todo` → `doing`：开始执行任务
- `doing` → `done`：标记任务完成
- `done` → `doing`：重新开始
- `*` → `deleted`：删除任务（可从垃圾箱恢复）

#### 优先级与难度

- **优先级**：
  - 0 = 低（周期长、不紧急）
  - 1 = 中（普通任务）
  - 2 = 高（紧急、重要）
  
- **难度**：预估完成任务所需工作量（会影响优先级计算）
  - 简单（30 分钟内）
  - 中等（1-2 小时）
  - 困难（半天以上）

#### 截止日期

设置任务的完成期限，会影响优先级计算：

- 距离期限越近，优先级越高
- 超期任务会在 UI 中特别标记

### 批量编辑

#### 批量改变状态

在列表视图中：

1. 多选任务（勾选复选框）
2. 点击「更改状态」
3. 选择目标状态（如「已完成」）
4. 批量更新

#### 批量删除/恢复

- **删除**：选中任务 → 「删除」→ 任务进入垃圾箱
- **恢复**：在垃圾箱中选中 → 「恢复」→ 返回主任务列表
- **永久删除**：在垃圾箱中选中 → 「永久删除」→ 无法恢复

## 层级关系管理

### 设置父子关系

#### 方式 1：创建时指定

创建新任务时，可指定 parent_id 设置为某任务的子任务。

#### 方式 2：拖放改层级

在树视图中，通过拖放改变任务层级：

- 拖到另一任务上方 → 成为兄弟任务
- 拖到另一任务缩进位置 → 成为子任务
- 拖到根位置 → 成为顶级任务

### 层级深度

支持**无限层级**的多级子任务：

```
项目 A
  ├─ Phase 1
  │   ├─ 设计
  │   └─ 开发
  ├─ Phase 2
  │   ├─ 测试
  │   └─ 部署
  └─ Phase 3
      └─ 维护与优化
```

## 删除与恢复

### 软删除（推荐）

标记任务为「已删除」状态，任务进入垃圾箱但不会彻底删除。

**优点**：
- 可以恢复
- 不会丢失数据
- 可查看删除历史

**步骤**：
1. 选中任务
2. 点击「删除」
3. 任务移入垃圾箱

### 恢复删除的任务

1. 进入「垃圾箱」视图
2. 选中要恢复的任务
3. 点击「恢复」
4. 任务回到原位置

### 永久删除

从垃圾箱中彻底删除任务（**无法恢复**）。

**谨慎使用！**

1. 进入「垃圾箱」视图
2. 选中任务
3. 点击「永久删除」
4. 确认删除

## 使用技巧

### 💡 保持任务具体

- ❌ 不好："项目工作"
- ✅ 好："完成用户认证模块的前端实现"

具体的任务更容易被 AI 分解，也更容易执行。

### 💡 合理设置截止日期

- 为重要任务设置明确的截止日期
- 系统会自动调整优先级
- 超期任务会被特别标记

### 💡 利用描述字段

在描述中记录：
- 任务的具体要求
- 相关的链接或参考资料
- 完成的检查清单

### 💡 定期清理垃圾箱

定期清空垃圾箱，避免数据堆积。

### 💡 有效利用难度评估

准确评估难度会帮助系统更好地计算优先级：
- 简单任务 → 低难度 → 可快速完成
- 复杂任务 → 高难度 → 提前安排
