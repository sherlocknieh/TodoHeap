# 任务管理详解

如何在 TodoHeap 中创建、编辑、完成和删除任务。

## 任务属性

| 属性 | 说明 | 是否必填 |
| --- | --- | --- |
| 标题 | 任务名称 | 是 |
| 详情 | 详细说明，支持 Markdown | 否 |
| 截止时间 | 完成期限，参与优先级计算 | 否 |
| 难度 | 预估工时（小时，支持 0.25 步进） | 否 |
| 完成时间 | 勾选完成时自动记录 | 只读 |

## 创建任务

### 快速创建

在列表视图顶部的输入框写标题，回车即可：新任务会立即出现在列表中，默认未完成。

### 用对话创建

当任务本身还很模糊时，打开 AI 视图，直接描述你想做的事，Agent 会判断是否拆成任务树：

```
输入：下个月把个人网站重新做一遍
↓
Agent 调用工具 → 生成若干任务与子任务
```

详见 [AI 智能功能](./02.ai-features.md)。

## 编辑任务

### 打开详情面板

单击任意任务行，右侧打开详情面板；再次点击顶栏右侧的面板按钮可以收起或展开。

面板底部固定显示子任务列表：只列出当前任务的直接子任务，不展开更深层级，点击任一条可切换到该任务；下方可以新建子任务，或从已有任务中选择一个链接为本任务的子任务（形成多父关系）。鼠标移到子任务行上可取消链接，只解除本任务的父子引用，任务本身与其他父关系不受影响。

### 可直接编辑的字段

| 字段 | 编辑方式 |
| --- | --- |
| 标题 | 直接改，失焦即保存 |
| 截止时间 | 详情面板选择日期时间；也可在任务行用日历按钮快速设为今天/明天/本周末 |
| 难度 | 输入工时，失焦即保存 |
| 详情 | Markdown 编辑器，失焦即保存 |

### 完成与取消完成

点击任务行左侧的复选框，在「待办」与「已完成」之间切换。已完成任务会从主列表移到底部「已完成」区域，展开后可以点回去取消完成。

切换完成状态后底部会弹出提示，几秒内可以点「撤销」还原。

「已完成」区域标题右侧的垃圾桶按钮可以一键清除：整棵已完成子树会移入回收站，误删可从回收站恢复。

### 重命名

双击任务标题进入行内编辑：回车保存，Esc 取消。

## 任务层级

任务支持无限层级，父子关系由父节点的 `child_ids` 保存；一个任务可以挂在多个父节点下，环也是合法数据，视图会把再次出现的引用标记为回边。

| 目的 | 操作 |
| --- | --- |
| 添加子任务 | 任务行「更多」菜单 → 添加子任务，或详情面板底部的「新建子任务」 |
| 链接已有任务 | 详情面板底部选择任务 → 链接为子任务，形成多父关系 |
| 取消链接 | 详情面板子任务行或列表视图回边行悬停 → 取消链接图标，仅解除该父子引用，任务本身保留 |
| 调整层级 | 在详情面板链接目标父任务；树视图用于查看关系，不直接编辑 |
| 折叠子任务 | 点击父任务左侧的箭头 |

列表视图按层级缩进显示，折叠父任务时其所有后代一并隐藏。

## 删除与恢复

- **删除**：任务行的删除按钮，任务进入回收站
- **恢复**：在回收站中选中该任务 → 恢复
- **永久删除**：在回收站中永久删除，不可撤销

父任务仍在回收站时，子任务不能单独恢复，需要先恢复父任务。

## 优先级怎么来的

优先级由系统自动计算，不再手动设置。堆视图排序会综合截止时间、完成进度、子任务复杂度三个维度算出得分并重排。

日常不需要维护优先级——看堆视图顶部的任务即可。
