# 侧栏开合与窗口宽度

左侧栏有两种形态：宽屏（≥ 768px）下是挤压中栏的常驻栏，窄屏下是覆盖内容的浮层抽屉。显示状态因此拆成两套，互不覆盖。

## 状态构成

| 状态 | 持久化 | 作用范围 |
| --- | --- | --- |
| `sidebar-open`（宽屏偏好） | 是，`todoheap:ui:sidebar-open` | 只是宽屏下是否显示侧栏，由用户手动开合决定 |
| 抽屉开关（窄屏） | 否，仅当次会话 | 窄屏浮层是否展开，收窄时自动关闭 |

`showLeftSidebar` 是 computed，按当前宽度选择上面哪套：

- 宽屏读写 `sidebar-open`；
- 窄屏读写抽屉开关。

因此同一处「关闭侧栏」在两种宽度下影响不同状态，不会把窄屏的一次收起写成宽屏偏好。

## 宽度变化的规则

`window.addEventListener('resize')` 只做两件事：更新 `windowWidth`（供浮层判定），以及在**从宽屏收窄到窄屏**时把抽屉关掉，避免浮层盖住清单。

放手规则是「宽度只决定用哪套状态」：

- 宽屏拖窗口不会展开或收起侧栏，用户的偏好保持不变；
- 窄屏拉宽后显示宽屏偏好，偏好为收起就继续收起；
- 切换活动栏入口（清单／日程／AI）时宽屏打开侧栏展示该入口内容，窄屏保持抽屉关闭。

断点常量 `SIDEBAR_FLOAT_BREAKPOINT = 768` 需与模板里的 `md:` 保持一致。

## 验证

1. 宽屏收起侧栏，反复拖动窗口宽度（含跨越 768px），侧栏保持收起；
2. 宽屏展开侧栏，收窄到 768px 以下，浮层自动关闭且不遮住中栏；再拉宽，侧栏按偏好恢复展开；
3. 窄屏点 AI 侧栏里的会话、通知等入口时抽屉打开，点击浮层外关闭；
4. 刷新页面后，宽屏偏好与刷新前一致。
